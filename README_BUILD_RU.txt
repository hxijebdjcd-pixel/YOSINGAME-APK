YOSINGAME — сборка APK без Google Colab

В архиве уже есть проект Kivy и настройка автоматической сборки через GitHub Actions.
Сам APK не включён: его должен собрать Android build environment в GitHub Actions.

Как получить APK (с телефона тоже можно):
1. Войдите или создайте аккаунт GitHub.
2. Создайте новый репозиторий, например YOSINGAME-Android. Для простоты можно сделать Public.
3. Распакуйте этот ZIP. Загрузите ВСЕ файлы и папки из него в корень репозитория. Важно: папка .github тоже должна загрузиться; если файловый менеджер скрывает её, используйте GitHub website и создайте путь .github/workflows/build-apk.yml.
4. Откройте вкладку Actions репозитория. Если GitHub попросит включить Actions, нажмите разрешить.
5. Выберите workflow “Build YOSINGAME APK” и нажмите Run workflow. Если он уже запустился автоматически после загрузки файлов, откройте его последний запуск.
6. Дождитесь зелёной отметки. Внизу страницы запуска в разделе Artifacts нажмите YOSINGAME-APK и скачайте ZIP.
7. Распакуйте скачанный ZIP — внутри будет файл .apk. Перенесите его на Android и установите. Android может попросить разрешить установку из этого источника.

Если сборка упадёт:
Откройте запуск в Actions, найдите первую красную ошибку и пришлите скриншот или скопируйте текст ошибки сюда — помогу исправить.

Важно:
- Google Colab не используется.
- Нужен интернет при сборке и аккаунт GitHub.
- APK пока не собран и не проверен на устройстве; результат зависит от того, пройдёт ли сборка.
- Не загружайте в публичный репозиторий личные пароли, ключи или приватные данные.
