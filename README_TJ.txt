YOSINGAME барои сохтани APK

Ин ZIP лоиҳаи Android аст, на APK-и тайёр. Барномаи Windows-и Tkinter мустақиман ба Android табдил намешавад; main.py ин ҷо бо Kivy барои телефон бозсозӣ шудааст.

Сохтани APK дар Linux/Google Colab:
1) ZIP-ро кушоед.
2) Python 3 ва Buildozer насб кунед.
3) Дар ҳамин папка иҷро кунед: buildozer android debug
4) APK дар папкаи bin пайдо мешавад.

Эзоҳ: сохтани APK дар Windows 7 бевосита одатан кор намекунад; Linux ё муҳити абрӣ лозим мешавад. Пеш аз насб APK-ро санҷед.
